# Technical Glossary

- **WebContainer**: In-browser WebAssembly-based operating system capable of running Node.js.
- **SharedArrayBuffer**: JavaScript shared memory feature enabling multi-threaded WebAssembly execution.
- **TRTC**: Tencent Real-Time Communication, a commercial WebRTC platform for audio and video streaming.
- **UserSig**: Cryptographic HMAC-SHA256 signature used to authenticate Tencent TRTC client sessions.
- **CRDT**: Conflict-free Replicated Data Type, a data structure that enables decentralized multi-user synchronization.
