# F4: TRTC Enterprise Chat & Video Calling

## Overview
Enterprise audio/video and instant messaging integration powered by Tencent Cloud TRTC Chat UIKit.

## Say It Out Loud
> "For enterprise communications, `chat-app-main` integrates Tencent Cloud's TRTC UIKit, using HMAC-SHA256 UserSig tokens generated in `server.js` for authenticated audio and video rooms."
