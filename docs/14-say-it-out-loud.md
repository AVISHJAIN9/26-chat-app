# Say It Out Loud: Spoken Interview Scripts

## Project Pitch (60 Seconds)
> "I built the Multi-Project Chat & AI Collaboration Suite, featuring Soen, an intelligent in-browser cloud IDE. Built with React 18, Express, Socket.IO, Redis, and MongoDB, Soen integrates Google Gemini AI to synthesize full-stack web applications and boots real Node.js runtimes directly inside the user's browser using the WebContainer WebAssembly API. The suite also integrates an enterprise messaging and video application powered by Tencent Cloud TRTC."

## Feature Scripts
### F1: AI Code Generation via Gemini
> "I built the AI Code Generation engine in `ai.service.js` using Google Gemini. When a developer submits a prompt, our system prompt instructs Gemini to output a strict JSON abstract syntax tree representing files and directories, mounting them directly into our virtual filesystem."

### F2: In-Browser WebContainers
> "Rather than maintaining expensive backend cloud sandboxes, I leveraged the WebContainer API to boot a complete Node.js micro-operating system directly inside the user's browser using WebAssembly with sub-second startup times."
