# Frequently Asked Questions: Soen AI Workspace & Real-time Chat

### 1. What is Soen AI Workspace & Real-time Chat?
Collaborative messaging workspace with real-time WebSocket channels and MongoDB Atlas persistence.

### 2. What technology stack does it use?
Built with Node.js (Express, Socket.io, MongoDB Atlas), Vanilla JS / CSS3.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/26-chat-app/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
